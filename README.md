# FolioPort ⚡

> **Interactive 3D Portfolio & Systems Showcase**  
> Architecting resilient distributed systems and next-generation interactive web experiences.

Built with **React 18**, **Three.js**, **GSAP**, **Lenis Smooth Scroll**, and **Tailwind CSS**.

---

## 🚀 Overview

**FolioPort** is an editorial, high-performance portfolio crafted for showcasing low-level systems engineering and creative frontend craftsmanship.

- **Interactive 3D & Canvas**: Custom Three.js shaders and interactive canvas experiences
- **Kinetic Typography & Motion**: Powered by GSAP animations, SVG curtain transitions, and magnetic interactions
- **Terminal & Systems Lab**: Interactive terminal interface, shader telemetry, and experiment showcase
- **Smooth Audio & Scroll**: Immersive Web Audio synthesizer cues and Lenis virtualized smooth scrolling
- **Dark / Light System**: Adaptive palette with rich liquid-glass UI cards

---

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **3D & Graphics**: Three.js, Custom Shaders
- **Animations**: GSAP, Lenis Smooth Scroll
- **Styling**: Tailwind CSS, PostCSS, Lucide Icons
- **Audio**: Web Audio API Synthesizer

## 📦 Getting Started

### Prerequisites

- Node.js (v18+ recommended)
- npm or pnpm or yarn

### Installation

```bash
# Clone repository
git clone https://github.com/watchknight/FolioPort.git
cd FolioPort

# Install dependencies
npm install

# Start development server
npm run dev
```

### Build

```bash
npm run build
npm run preview
```
